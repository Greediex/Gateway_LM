# FND-01 — Function Contract v0.2 Implementation Plan

**Goal:** Chuẩn hóa metadata Function/Port và exact version selection, kiểm tra bằng test vectors, giữ nguyên contract/digest v0.1.

**Architecture:** Schema self-contained và API kiểm tra một document độc lập; dùng `jsonschema` hiện có. Không nạp catalog hoặc tạo quyền thực thi.

**Tech Stack:** Python 3.12, JSON Schema Draft 2020-12, unittest.

**Spec:** [Foundation design](../specs/2026-11-13-command-catalog-v02-design.md), [chuẩn chi tiết FND-01](../../contracts/catalog-v02/README.md).
